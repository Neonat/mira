# Australia and UAE Mixed Retrieval Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enable approved Australian and UAE federal sources with source-specific acquisition, complete permitted evidence storage, and shareable validation reports in PR13.

**Architecture:** Extend the existing allow-listed HTTP/scout pipeline rather than add a second crawler. Australian Federal Register JSON discovers dated publications; direct files supply legal text. UAE federal hubs discover same-host PDFs. Browser automation remains permission-gated and is not enabled for these profiles. PostgreSQL retains complete permitted text/native metadata; pgvector remains experimental and cannot receive UAE text without embedding permission.

**Tech Stack:** Python, existing PostgreSQL/pgvector evidence store, Streamlit, existing HTML report renderer; standalone HTML validation reports.

**Spec:** User-approved approach in [source-method pilot](../../..//eval/evidence/2026-11-10-country-method-pilot.md), with the additions below.

## Design and approaches

The user selected the mixed approach after a bounded source-method pilot. A generic browser crawler adds latency and can capture a viewer instead of its publication; an API-only pipeline cannot cover UAE PDFs or Australian guidance. Build on the existing mixed HTTP path with a small native metadata adapter. Preserve Ewen's budget/category/verification guards and all historical artifacts.

Australia means Federal Register legislation and AUSTRAC public guidance, subject to live robots checks. UAE means Central Bank federal public sources only; rulebook subdomains, DIFC/DFSA and Malaysia remain outside the approved profiles. MAS remains inactive. Do not equate Australia/UAE enablement with complete national regulatory coverage.

Complete native JSON is retained with permitted text, separately from claim summaries. Discovery metadata does not become legal-text passages. Publication/effective/registration dates stay distinct; unknown registration dates do not become invented publication dates. Source attribution survives evidence capture and frozen report rendering. Report links use readable publisher destinations.

## Acceptance and limits

AU native discovery must lead to eligible fixed publications, UAE hub links must stay within federal source grants, full extracted text/native JSON must survive storage, and no discovery metadata may masquerade as legal text. Disabled sources stay disabled, UAE is not externally embedded, hybrid stays explicitly experimental, and reports include readable source links and required reuse notices. A bounded live failure is reported rather than replaced or hidden; human relevance/precision and national completeness are not established by an integration test.
