## Phase 2 design and recommended policy
A separate claim-level corroboration service searches eligible saved evidence first; optional bounded targeted discovery reuses the Phase-1 acquisition boundary. Default maximum 2 targeted queries, 5 candidate documents, 20 passages and 30 seconds per claim; automatic live discovery remains disabled without explicitly supplied adapter/authorization. Existing run verification remains responsible for truth/support; corroboration never downgrades authoritative primary-source facts merely for lack of an independent source.

Each assessment binds exact verification input, proposition/entity/jurisdiction/date/quantity/regulatory status, primary evidence and candidate saved passage/version IDs, exact quotations, support/conflict assessment, origin relationship, explanation, search limits/exhaustion and checked time. A fresh-context assessor may propose semantic support and origin relationships, but code validates exact quotes, eligible versions, workspace, sources and explicit relationship evidence. Unknown origin cannot establish independence. Same publication, landing/PDF aliases, same source organization, identical content, shared announcement origins and syndication are dependent. Independent support requires explicit reason/origin evidence rather than different URLs. Mismatched propositions cannot corroborate. Preserve conflicting passages even when other candidates support the claim.

Outcomes: independently_corroborated; primary_source_only; conflicting_evidence; not_checked; inconclusive. Authoritative primary_source_only is informational. Recommended sign-off policy: display outcomes and reasons; no blanket requirement for two sources. Conflicts/inconclusive outcomes require auditor acknowledgement via the existing review decision; corroboration itself never issues action recommendations. These are implementation defaults, not a claim that the product owner adopted an enterprise policy.

Persist append-only assessments in a new compatible migration and worker-only writes with workspace RLS reads. No invented historical rows. Freeze exact corroboration results plus evidence in new reviewed snapshots; absent legacy results are not_checked. Bind current assessments to verification/reviewer input so subsequent changed corroboration requires fresh verification/review before a new sign-off. Existing signed snapshots never consult live assessment tables.

Auditor output shows assessment status/date, candidate citations with exact quotes, origin decision and explanation, separately from fact verification and human review decisions. Frozen bundle version extension remains compatible with existing contract-1.4 artifacts; no regeneration of incomplete legacy bundles.

Acceptance: independent support, copied reporting, mismatch, contradiction, primary-only, exhausted budgets, stale evidence, cross-workspace refusal and frozen output. Independent focused review; complete local database tests/eval; checkpoint and PRD update; commit/push stacked PR without merging/deploying.

## Builder review resolutions
- Acyclic bindings: `base_evidence_input` contains only existing claim/support/dependency evidence. An assessment records this base plus its candidate evidence; full verification and reviewer inputs additionally contain the latest immutable assessment per finding. The verifier receives that full context before its result is saved. SQL capture/subset and Python capture must agree; order latest assessments by a server-generated sequence. Existing inputs without assessments keep their contract-1.4 shape.
- Effective claim budgets are capped by the shared run's remaining tokens/documents/deadline. Failed queries/acquisitions consume their attempted allowance; assessor usage enters the same step ledger. Saved-only assessment needs no fetched-document allowance. No automatic live discovery is enabled by supplying a credential alone.
- Original capture digest remains separate from extraction identity. Extraction method/version/text hash participates in reuse identity so identical bytes with changed extraction cannot silently return prior passages. No historical passages are overwritten.
- Conflict has precedence over support in the summary. Origin decisions require specific retained evidence; a different domain alone cannot prove independence. Browser authorization defaults false, and unsupported browser mediation is a disclosed gap, never a path around robots/access blocks.
